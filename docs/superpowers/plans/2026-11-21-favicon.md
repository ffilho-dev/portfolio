> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the legacy `"FF"` monogram favicon with the `>F_` terminal-prompt developer portfolio icon across `src/app/icon.svg`, `src/app/favicon.ico`, and the `ffilho.dev` brand link in `src/components/SiteHeader.tsx`.

**Architecture:** `src/app/icon.svg` provides the vector `32×32` favicon with embedded `@media (prefers-color-scheme: dark)` rules aligned to the portfolio's Zinc + Petróleo (`#0F4C5C`) / Âmbar (`#E09F3E`) tokens. `src/app/favicon.ico` provides a multi-resolution (`16×16` and `32×32`, 32-bit RGBA) raster fallback of the same `>F_` mark. `src/components/SiteHeader.tsx` embeds an inline `aria-hidden="true"` SVG brand mark next to `{profile.handle}` that adapts to both system preference and manual `ThemeToggle` state.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript (`strict: true`), Tailwind CSS v4, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-21-favicon-design.md`

- Manual theme toggle sync on `SiteHeader`: inline SVG brand mark must respond to `.dark` on `document.documentElement` (tested in Task 2).

- Dark-tab contrast frame: `src/app/icon.svg` and `SiteHeader` brand mark must include the inner `#E09F3E` border in dark mode so the `#09090B` tile stays visible against dark browser bars and dark headers (tested in Task 1 and Task 2).

Add a `describe("favicon assets (>F_ terminal prompt)", ...)` block in `tests/site.test.ts` that reads `src/app/icon.svg` and `src/app/favicon.ico` via `node:fs`:

```ts
describe("favicon assets (>F_ terminal prompt)", () => {
  it("defines the >F_ terminal prompt geometry and Zinc/Petróleo/Âmbar adaptive palette in src/app/icon.svg", () => {
    const svg = readFileSync( resolve(process.cwd(), "src/app/icon.svg"), "utf8" );

    expect(svg).toContain('viewBox="0 0 32 32"');
    expect(svg).toContain("@media (prefers-color-scheme: dark)");
    expect(svg).toContain("#0F4C5C");
    expect(svg).toContain("#A5F3FC");
    expect(svg).toContain("#FFFFFF");
    expect(svg).toContain("#09090B");
    expect(svg).toContain("#E09F3E");
    expect(svg).toContain("#FAFAFA");
    expect(svg).not.toContain("#161B22");

    // Chevron >, letter F, and terminal cursor _
    expect(svg).toContain("M5.5 11L11.5 16L5.5 21");
    expect(svg).toContain("M15 9H24V12.5H18.5V15H23V18.5H18.5V23H15V9Z");
    expect(svg).toContain('width="5.5" height="3"');
  });

  it("provides a valid multi-resolution (16x16 and 32x32, 32-bpp) src/app/favicon.ico updated from the legacy FF icon", () => {
    const ico = readFileSync(resolve(process.cwd(), "src/app/favicon.ico"));

    // ICONDIR header: reserved=0, type=1 (ICO), count=2
    expect(ico.readUInt16LE(0)).toBe(0);
    expect(ico.readUInt16LE(2)).toBe(1);
    expect(ico.readUInt16LE(4)).toBe(2);

    // Entry 1: 16x16, 32 bpp
    expect(ico.readUInt8(6)).toBe(16);
    expect(ico.readUInt8(7)).toBe(16);
    expect(ico.readUInt16LE(12)).toBe(32);

    // Entry 2: 32x32, 32 bpp
    expect(ico.readUInt8(22)).toBe(32);
    expect(ico.readUInt8(23)).toBe(32);
    expect(ico.readUInt16LE(28)).toBe(32);
  });
});
```
